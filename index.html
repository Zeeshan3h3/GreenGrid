Platform Documentation

CanopyAI is an automated, high-performance platform for forest inventory, crown detection, and canopy area estimation. Designed for speed, memory efficiency, and a premium user experience, the platform processes drone orthomosaics to deliver actionable ecological metrics and exportable GIS deliverables.

Machine Learning Models

  • DeepForest (RetinaNet)
    Used for individual tree stem counting and bounding box detection. It scans the image in overlapping patches to find distinct tree crowns.
  • Restor OAM-TCD (Segformer-MIT-B2)
    Used for pixel-level canopy coverage estimation. A Vision Transformer that performs semantic segmentation to calculate the exact surface area of the forest.

Input Data Requirements

  • File Format: GeoTIFF (.tif or .tiff) with embedded spatial metadata.
  • Bands: Standard RGB (3-band).
  • Resolution: High-resolution drone imagery (5cm to 50cm per pixel) yields the best crown detection.
  • File Size: Tiled inference handles large files, but for snappy API responses on CPU, images between 10MB to 50MB are recommended.
  • Boundary (Optional): A .kml polygon can be uploaded to clip the analysis to a specific boundary.

How to Use

  1. Upload your GeoTIFF file in the Upload Datasets panel. Optionally, upload a KML boundary.
  2. Adjust the Detection Confidence slider. Increase it to eliminate false positives (like bushes); decrease it to detect smaller saplings.
  3. Click Execute Analysis. The backend will process the imagery and stream the results back.
  4. Review the KPI metrics, inspect the dual-model overlay, and click Download .ZIP to export your GIS deliverables.
